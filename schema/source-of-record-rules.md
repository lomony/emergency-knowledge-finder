# Source-of-record rules

Which document is the authority for each kind of figure, and how newer or conflicting figures are handled (v0.2).

| Metric family | Source of record (rank 1 for this family) | Other sources (lower rank) | Update trigger | Supersession and conflict rule | Owner role (internal deployment) |
|---|---|---|---|---|---|
| Appeal requirement (total, by sector) | HAC country appeal (latest revision); HAC overview for the global table | Situation reports (may round), press releases | Revised HAC appeal | Newest HAC revision supersedes. Situation report text that differs is flagged as a variant and never overrides. | Curator: PFP Emergency Fundraising Unit. Publisher: UNICEF country or regional office |
| Funding status (mobilised, received, other resources, carry-over, gap) | Latest situation report (funding overview and annex table) | Press releases and secondary pages (often lag) | Each new situation report | Newer as-of supersedes. Record calculation_basis. A change of basis (for example EPF loans included or excluded) is flagged and not compared directly. | As above |
| People and children in need; IDPs | HAC appeal or situation report 'Situation in numbers', with the underlying source (HNRP, IOM DTM) | Narrative text in the same report, press releases | New plan or data release | Newer as-of supersedes. Differences inside one report are flagged. Cite the underlying source. | As above |
| Sudden-onset impact (affected, deaths, missing) | Latest situation report citing government authorities | Press releases (initial estimates), secondary pages | Each situation report | Newer supersedes. Press release figures are marked 'initial'. | As above |
| Programme results (cumulative) and targets | Latest situation report results table; targets from the HAC appeal | Press stories | Each situation report | Newer cumulative supersedes. Compare across reports only when the indicator wording matches. | As above |
| Organisational funding (income, private sector revenue) | Funding Compendium for income; PFP report to the Executive Board for fundraising results | Briefing slides, press, National Committee reports | Annual | Each answers a different question. Never merge or average them. | Publishers: PFP and the public partnerships division |
| All families: retention |  |  |  | Superseded documents and figures are kept with status 'superseded' for audit and excluded from 'current' answers. |  |
